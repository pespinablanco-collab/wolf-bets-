PABLO23 BETS - IMAGENES
========================

Puedes reemplazar los placeholders por tus propias imágenes.

1) assets/presentation/banner-placeholder.jpg
   -> banner grande de presentación.

2) assets/team-logos/
   -> escudos. El pablo23.js ya acepta:
      home_logo / away_logo
      home_team_logo / away_team_logo
      home_crest / away_crest
      home_badge / away_badge
      home_image / away_image
   También puedes mapearlos manualmente en TEAM_LOGOS.

3) assets/team-shirts/
   -> camisetas/jugadores para tarjetas visuales.

4) assets/promos/
   -> banners o promociones.
